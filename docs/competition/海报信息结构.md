# NewsBrief 竞赛海报信息结构

## 顶部

项目名称：NewsBrief 中文新闻可信阅读工作台。

一句话说明：以原文证据链为核心的本地新闻摘要、事实理解与人机协作工具。

## 中部左侧：问题与方案

用三项问题说明信息过载、摘要不可核验、生成内容难以控制。用“输入新闻 → 本地分析 → 事实卡片 → 证据约束 → 可复现评测”流程图回应。

## 中部右侧：核心创新

1. 新闻感知排序：PageRank、标题、导语与数字事实融合。
2. 事实覆盖 MMR：选择重要且低重复、能覆盖不同事实维度的句子。
3. 可编辑证据链：固定与排除原文句后重新生成。
4. 可信度实验室：Lead-3、基础 TextRank、V1.4、V2.0 的统一评测。

## 底部：成果与证据
